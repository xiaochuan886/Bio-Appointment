## 筛选器组件详解

### 默认状态（未筛选）

```
┌─────────────────────────────┐
│ 🔍 资源筛选                 │
│                             │
│ ☐ 护士（含护士长）          │
│                             │
│ ☐ 房间资源                  │
│                             │
│ ─────────────────────────── │
│ 未选择筛选条件，显示所有资源│
└─────────────────────────────┘

说明：
- 标题：资源筛选（无"已筛选"标记）
- 两个复选框都未选中
- 底部说明：显示默认状态
```

### 筛选护士状态

```
┌─────────────────────────────┐
│ 🔍 资源筛选（已筛选）       │
│                             │
│ ☑ 护士（含护士长）          │  ← 已选中
│                             │
│ ☐ 房间资源                  │
│                             │
│ ─────────────────────────── │
│ 仅显示护士和护士长资源      │  ← 动态说明
└─────────────────────────────┘

说明：
- 标题：资源筛选（已筛选）← 状态指示
- 护士复选框已选中（☑）
- 房间复选框未选中（☐）
- 底部说明：更新为当前筛选状态
```

### 筛选房间状态

```
┌─────────────────────────────┐
│ 🔍 资源筛选（已筛选）       │
│                             │
│ ☐ 护士（含护士长）          │
│                             │
│ ☑ 房间资源                  │  ← 已选中
│                             │
│ ─────────────────────────── │
│ 仅显示房间资源              │  ← 动态说明
└─────────────────────────────┘

说明：
- 标题：资源筛选（已筛选）
- 护士复选框未选中（☐）
- 房间复选框已选中（☑）
- 底部说明：更新为当前筛选状态
```

### 全选状态

```
┌─────────────────────────────┐
│ 🔍 资源筛选                 │  ← 无"已筛选"标记
│                             │
│ ☑ 护士（含护士长）          │  ← 已选中
│                             │
│ ☑ 房间资源                  │  ← 已选中
│                             │
│ ─────────────────────────── │
│ 显示所有资源                │  ← 动态说明
└─────────────────────────────┘

说明：
- 标题：资源筛选（无"已筛选"标记）
- 两个复选框都已选中
- 底部说明：显示所有资源
- 效果等同于未筛选状态
```

## 交互流程

### 流程1：从默认到筛选护士

```
步骤1：初始状态
┌─────────────┐
│ ☐ 护士      │
│ ☐ 房间      │
└─────────────┘
显示：所有资源

↓ 用户点击"护士"复选框

步骤2：筛选激活
┌─────────────┐
│ ☑ 护士      │  ← 选中
│ ☐ 房间      │
└─────────────┘
显示：仅护士资源

↓ 看板立即更新（< 300ms）

步骤3：结果显示
看板仅显示护士排班区域
房间排班区域被隐藏
```

### 流程2：切换筛选条件

```
当前状态：
┌─────────────┐
│ ☑ 护士      │
│ ☐ 房间      │
└─────────────┘

↓ 用户点击"护士"复选框（取消选中）

过渡状态：
┌─────────────┐
│ ☐ 护士      │  ← 取消选中
│ ☐ 房间      │
└─────────────┘
显示：所有资源

↓ 用户点击"房间"复选框

最终状态：
┌─────────────┐
│ ☐ 护士      │
│ ☑ 房间      │  ← 选中
└─────────────┘
显示：仅房间资源
```

## 视觉元素说明

### 图标
- 🔍 Filter图标：表示筛选功能
- ☐ 空心复选框：未选中状态
- ☑ 实心复选框：选中状态

### 颜色
- 标题文字：默认前景色
- 复选框：主题色（选中时）
- 说明文字：灰色（muted-foreground）
- 边框：浅灰色（border）

### 间距
- 卡片内边距：16px（p-4）
- 元素间距：12px（space-y-3）
- 复选框与标签间距：8px（space-x-2）

### 字体
- 标题：14px，中等粗细（text-sm font-medium）
- 复选框标签：14px，正常粗细（text-sm font-normal）
- 说明文字：12px，正常粗细（text-xs）

## 使用提示

### 💡 提示1：快速切换
通过快速点击复选框，可以在不同视图之间快速切换，便于对比分析。

### 💡 提示2：状态指示
始终关注筛选器标题和底部说明，确保了解当前的筛选状态。

### 💡 提示3：月视图
在月视图中，筛选条件不影响显示，会显示明确的提示信息。

### 💡 提示4：无结果
如果筛选后看到"暂无符合筛选条件的资源"，说明当前没有该类型的资源。
