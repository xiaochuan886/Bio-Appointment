## 🎯 核心设计特性

### 1. 组合颜色展示

**渐变色方案**：排班卡片使用护士颜色到房间颜色的135度渐变
- 左侧：护士颜色（暖色调）
- 右侧：房间颜色（冷色调）
- 过渡：平滑的对角线渐变

```css
background: linear-gradient(135deg, 
  护士颜色 0%, 
  护士颜色 50%, 
  房间颜色 50%, 
  房间颜色 100%
);
```

### 2. 无障碍设计

**色盲友好特性**：
- ✅ 每个资源都有独特的图案纹理（圆点、条纹、网格等）
- ✅ 高对比度文字（白色文字 + 阴影效果）
- ✅ 边框和光环提供额外的视觉区分
- ✅ 悬停提示显示详细的文字信息

**WCAG AA标准**：
- 所有文字与背景的对比度 ≥ 4.5:1
- 交互元素具有明确的视觉反馈

### 3. 交互体验

**悬停效果**：
- 卡片透明度变化（opacity: 0.9）
- 阴影增强（hover:shadow-lg）
- 显示详细信息工具提示

**工具提示内容**：
- 客户姓名和服务时间
- 护士信息（姓名、技能等级、颜色标识）
- 房间信息（名称、类型、颜色标识）

### 4. 视觉层级

**卡片样式优先级**：
1. 急单：红色边框（最高优先级）
2. 已锁定：绿色边框（次优先级）
3. 筛选高亮：黄色光环（辅助标识）
4. 常规：渐变色背景

## 🎓 使用指南

### 护士长操作流程

1. **查看图例**：了解每个护士和房间的颜色标识
2. **识别排班**：通过渐变色快速识别护士-房间配对
3. **筛选资源**：选择特定护士或房间查看相关排班
4. **悬停查看**：鼠标悬停在卡片上查看详细信息
5. **点击编辑**：点击卡片进行排班调整

### 颜色识别技巧

- **左侧颜色** = 护士（暖色调）
- **右侧颜色** = 房间（冷色调）
- **红色边框** = 急单，需优先处理
- **绿色边框** = 已锁定，不可随意更改
- **黄色光环** = 当前筛选的目标

## 🔍 可访问性说明

### 色盲用户支持

- **红绿色盲**：使用图案纹理辅助识别
- **蓝黄色盲**：颜色对比度足够，文字清晰

### 屏幕阅读器支持

- 所有交互元素都有适当的ARIA标签
- 工具提示内容可被屏幕阅读器访问
- 语义化HTML结构

## 📊 设计原则

1. **直观性**：颜色编码一目了然
2. **一致性**：同一资源始终使用相同颜色
3. **可区分性**：护士（暖色）vs 房间（冷色）
4. **可访问性**：支持色盲用户
5. **美观性**：专业、整洁、现代
6. **响应性**：适配不同设备尺寸

## 📝 维护说明

### 添加新护士/房间

1. 系统会自动循环使用预定义的颜色方案
2. 超过10个资源时，颜色会重复使用（通过索引取模）
3. 建议定期审查颜色分配，确保同时在岗的资源颜色不重复

### 颜色调整

如需调整颜色方案，请修改 `src/utils/colorSystem.ts` 中的常量：
- `NURSE_COLORS`：护士颜色数组
- `ROOM_COLORS`：房间颜色数组
- `STATUS_COLORS`：状态颜色对象
