# 资源筛选功能使用指南

## 快速开始

资源筛选功能帮助您在资源看板上快速定位和查看特定类型的资源，让大规模资源管理更加高效。

## 功能位置

在**智能排班看板**页面，资源筛选器位于页面右侧边栏的顶部，紧邻"排班待办"卡片上方。

```
┌─────────────────────────────────┬─────────────────┐
│                                 │  资源筛选       │
│      资源看板                   │  □ 护士         │
│                                 │  □ 房间资源     │
│                                 ├─────────────────┤
│                                 │  排班待办       │
│                                 │                 │
└─────────────────────────────────┴─────────────────┘
```

## 使用方法

### 基本操作

#### 1. 筛选护士资源
**目的**：仅查看护士和护士长的排班情况

**步骤**：
1. 找到"资源筛选"卡片
2. 勾选"护士（含护士长）"复选框
3. 资源看板立即更新，仅显示护士排班

**效果**：
- 日视图：仅显示"护士排班"区域
- 周视图：仅显示"周视图 - 护士排班"
- 月视图：显示所有排班（月视图不支持筛选）

#### 2. 筛选房间资源
**目的**：仅查看房间的使用情况

**步骤**：
1. 找到"资源筛选"卡片
2. 勾选"房间资源"复选框
3. 资源看板立即更新，仅显示房间排班

**效果**：
- 日视图：仅显示"房间排班"区域
- 周视图：仅显示"周视图 - 房间排班"
- 月视图：显示所有排班（月视图不支持筛选）

#### 3. 查看所有资源
**目的**：查看完整的资源分配情况

**方法一**：同时勾选两个复选框
- 勾选"护士（含护士长）"
- 勾选"房间资源"

**方法二**：取消所有勾选
- 取消勾选所有复选框

**效果**：显示所有房间和护士的完整排班

#### 4. 清除筛选
**步骤**：
1. 取消勾选所有复选框
2. 或者同时勾选两个复选框

**效果**：恢复显示所有资源

## 视图模式说明

### 日视图
- **完全支持筛选**
- 筛选后，隐藏不符合条件的资源区域
- 保留符合条件的资源区域的完整时间轴（08:00 - 18:00）

### 周视图
- **完全支持筛选**
- 筛选后，隐藏不符合条件的资源网格
- 保留符合条件的资源网格的完整周视图（周一到周日）

### 月视图
- **不支持资源类型筛选**
- 月视图显示所有排班的汇总统计
- 当有筛选条件激活时，会显示提示信息
- 提示内容："注意：月视图显示所有排班汇总，不区分资源类型"

## 状态指示

### 筛选器标题
- **未筛选**：显示"资源筛选"
- **已筛选**：显示"资源筛选（已筛选）"

### 筛选说明
筛选器底部会显示当前筛选状态的说明文字：

| 筛选状态 | 说明文字 |
|---------|---------|
| 未选择任何条件 | "未选择筛选条件，显示所有资源" |
| 仅选择护士 | "仅显示护士和护士长资源" |
| 仅选择房间 | "仅显示房间资源" |
| 同时选择两者 | "显示所有资源" |

### 无结果提示
当筛选条件导致没有资源显示时，看板会显示：
```
暂无符合筛选条件的资源
请调整筛选条件或清除筛选
```

## 实际应用场景

### 场景1：护士资源紧张时
**情况**：某天护士请假，需要重新分配护士资源

**操作**：
1. 勾选"护士（含护士长）"
2. 在日视图中查看当天护士排班
3. 识别空闲时段和重叠排班
4. 调整护士分配

**优势**：专注于护士资源，不被房间信息干扰

### 场景2：房间使用率分析
**情况**：需要分析VIP室和治疗区的使用情况

**操作**：
1. 勾选"房间资源"
2. 切换到周视图
3. 查看一周内各房间的使用频率
4. 识别空闲时段，优化排班

**优势**：清晰看到房间使用模式，便于资源优化

### 场景3：快速排班检查
**情况**：护士长需要快速检查今天的排班是否合理

**操作**：
1. 不选择任何筛选条件（显示所有资源）
2. 在日视图中查看完整排班
3. 检查房间和护士的匹配情况
4. 发现问题后，使用筛选器专注于特定资源类型

**优势**：先全局后局部，快速定位问题

### 场景4：周度资源规划
**情况**：每周一规划本周的资源分配

**操作**：
1. 切换到周视图
2. 先勾选"房间资源"，查看房间预订情况
3. 再勾选"护士（含护士长）"，查看护士排班
4. 对比两者，调整资源分配

**优势**：分步骤查看，避免信息过载

## 常见问题

### Q1：为什么月视图不支持筛选？
**A**：月视图是汇总视图，显示每天的排班总数，不区分具体的资源类型。如果需要查看特定资源类型的详细排班，请使用日视图或周视图。

### Q2：筛选后统计数据会变化吗？
**A**：不会。页面顶部的统计卡片（今日总数、待排班、急单、已锁定）显示的是完整数据，不受筛选条件影响。

### Q3：筛选条件在切换视图时会保留吗？
**A**：会。在日视图、周视图、月视图之间切换时，筛选条件会保持不变。

### Q4：如何快速恢复显示所有资源？
**A**：有两种方法：
1. 取消勾选所有复选框
2. 同时勾选两个复选框

### Q5：筛选会影响数据加载速度吗？
**A**：不会。筛选是在前端进行的，不需要重新从服务器加载数据，响应速度非常快。

## 提示与技巧

### 💡 技巧1：使用筛选提高专注度
在处理复杂排班时，使用筛选器隐藏暂时不需要关注的资源类型，可以提高工作效率。

### 💡 技巧2：结合视图模式使用
- 日视图 + 筛选：适合详细调整特定资源的排班
- 周视图 + 筛选：适合分析特定资源的使用趋势
- 月视图：适合查看整体排班情况（不使用筛选）

### 💡 技巧3：快速切换筛选条件
通过快速勾选/取消勾选复选框，可以在不同资源类型之间快速切换视图，便于对比分析。

### 💡 技巧4：注意筛选状态指示
始终关注筛选器标题和底部说明，确保了解当前的筛选状态，避免遗漏重要信息。
