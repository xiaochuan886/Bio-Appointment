# 预约详情增强功能手动测试指南

## 功能概述
本次增强为预约详情对话框添加了以下功能：
1. 显示预约人（销售）信息
2. 优化多客户预约的显示方式
3. 正确展示客户数量统计

## 测试环境准备

### 1. 启动服务
```bash
# 启动API服务器
node server/api-server.cjs

# 启动前端开发服务器
npm run dev
```

### 2. 创建测试数据
```bash
# 创建包含销售信息和多客户的测试预约
node create-test-appointment-with-sales.cjs
```

2. 使用默认凭据登录（admin / admin123）
3. 确认成功登录并跳转到首页

## 预期结果

### 预约人信息区域
- 浅灰色背景 (`bg-muted/30`)
- 显示用户图标和"预约人:"标签
- 销售姓名和角色标签
- 如果无销售信息，显示"未指定"

### 客户信息区域
- 蓝色背景 (`bg-blue-50`)
- 主客户信息和客户数量统计
- 同行客户以蓝色标签形式显示
- 客户数量计算正确（主客户 + 同行客户）

### 数据验证
- API返回包含销售信息字段：`sales_name`, `sales_username`, `sales_role`
- API返回包含客户信息字段：`companion_names`, `total_people`
- 前端正确解析和显示所有字段

## 故障排除

### 如果看不到测试数据
1. 确认API服务器正在运行
2. 重新运行测试数据创建脚本
3. 检查数据库连接

### 如果预约详情不显示新字段
1. 确认API服务器已重启（应用了新的查询）
2. 检查浏览器控制台是否有错误
3. 验证API响应数据结构

### 如果UI显示异常
1. 检查CSS类名是否正确
2. 确认Tailwind CSS样式加载
3. 验证组件代码更新
