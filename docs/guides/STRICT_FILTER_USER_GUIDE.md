# 严格筛选模式 - 用户使用指南

## 🎯 什么是严格筛选模式？

严格筛选模式是一种**只显示你选择的内容**的筛选方式。

### 核心理念

```
选什么，看什么
不选的，就隐藏
```

### 与旧版本的区别

| 对比项 | 旧版本（强调模式） | 新版本（严格筛选） |
|-------|------------------|------------------|
| 显示内容 | 显示所有，高亮匹配 | 只显示选中的 |
| 未选资源 | 灰色显示 | 直接隐藏 |
| 视觉标记 | ⭐标记 | 无需标记 |
| 界面复杂度 | 较复杂 | 更简洁 |

## 📖 基础使用

### 1. 打开筛选器

在智能排班页面右侧，找到"资源筛选"卡片。

### 2. 选择资源

**护士筛选**：
- 勾选你想查看的护士
- 可以选择多个
- 已选数量会显示在右上角

**房间筛选**：
- 勾选你想查看的房间
- 可以选择多个
- 已选数量会显示在右上角

### 3. 查看结果

勾选后，甘特图会**立即更新**，只显示你选中的资源。

### 4. 清除筛选

点击右上角的"清除"按钮，恢复显示所有资源。

## 🔍 筛选规则详解

### 规则1：只选护士

**效果**：显示选中护士的所有排班

**示例**：
```
选择：护士A

显示：
- 护士A在VIP室1的排班
- 护士A在VIP室2的排班
- 护士A在治疗区A的排班
- ...（护士A的所有排班）

隐藏：
- 护士B、护士C等其他护士
```

### 规则2：只选房间

**效果**：显示选中房间的所有排班

**示例**：
```
选择：VIP室1

显示：
- 护士A在VIP室1的排班
- 护士B在VIP室1的排班
- 护士C在VIP室1的排班
- ...（VIP室1的所有排班）

隐藏：
- VIP室2、治疗区A等其他房间
```

### 规则3：同时选护士和房间

**效果**：只显示同时满足两个条件的排班（交集）

**示例**：
```
选择：护士A + VIP室1

显示：
- 护士A在VIP室1的排班

隐藏：
- 护士A在其他房间的排班
- 其他护士在VIP室1的排班
- 其他所有排班
```

### 规则4：选多个护士

**效果**：显示所有选中护士的排班（并集）

**示例**：
```
选择：护士A + 护士B

显示：
- 护士A的所有排班
- 护士B的所有排班

隐藏：
- 护士C、护士D等其他护士
```

### 规则5：选多个房间

**效果**：显示所有选中房间的排班（并集）

**示例**：
```
选择：VIP室1 + VIP室2

显示：
- VIP室1的所有排班
- VIP室2的所有排班

隐藏：
- 治疗区A、治疗区B等其他房间
```

## ⚠️ 注意事项

### 注意1：筛选后看不到其他资源

这是正常的！严格筛选模式就是只显示你选中的资源。

**解决方法**：点击"清除"按钮，恢复显示所有资源。

### 注意2：筛选结果为空

如果筛选后没有显示任何排班，可能是：
- 选中的资源今天没有排班
- 筛选条件太严格（同时选了护士和房间，但没有匹配的排班）

**解决方法**：
- 检查筛选条件是否正确
- 尝试放宽筛选条件
- 清除筛选，重新选择

### 注意3：忘记清除筛选

如果你忘记清除筛选，可能会误以为系统只有少量资源。

**提示**：
- 注意顶部的"资源筛选（已启用）"标识
- 注意蓝色的"严格筛选模式"提示框
- 养成使用后清除筛选的习惯

## 📞 常见问题

### Q1：为什么筛选后看不到其他资源了？

**A**：这是严格筛选模式的特点。只显示你选中的资源，未选中的会被隐藏。如果需要看到所有资源，请点击"清除"按钮。

### Q2：如何恢复显示所有资源？

**A**：点击筛选器右上角的"清除"按钮，或者取消勾选所有复选框。

### Q3：可以同时选择多个护士和多个房间吗？

**A**：可以！系统会显示所有选中护士在所有选中房间的排班。

### Q4：筛选后为什么没有显示任何排班？

**A**：可能是选中的资源今天没有排班，或者筛选条件太严格。尝试放宽条件或检查日期筛选。

### Q5：筛选功能会影响数据吗？

**A**：不会！筛选只是改变显示，不会修改或删除任何数据。

### Q6：筛选后可以编辑排班吗？

**A**：可以！筛选不影响编辑功能，你可以正常点击排班卡片进行编辑。

### Q7：筛选条件会被保存吗？

**A**：当前版本不会保存筛选条件。刷新页面后会恢复默认状态（显示所有资源）。

### Q8：如何快速切换不同的筛选条件？

**A**：直接勾选或取消勾选复选框，系统会立即更新显示。不需要点击"确认"按钮。
