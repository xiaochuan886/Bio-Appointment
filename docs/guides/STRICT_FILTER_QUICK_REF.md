# 严格筛选模式 - 快速参考卡

## 🎯 核心理念

```
选什么，看什么
不选的，就隐藏
```

## 📋 筛选规则速查表

| 筛选条件 | 显示内容 | 示例 |
|---------|---------|------|
| 无筛选 | 所有资源 | 显示所有护士和房间 |
| 只选护士 | 该护士的所有排班 | 选护士A → 显示护士A的所有排班 |
| 只选房间 | 该房间的所有排班 | 选VIP室1 → 显示VIP室1的所有排班 |
| 护士+房间 | 同时满足的排班（交集） | 选护士A+VIP室1 → 只显示护士A在VIP室1的排班 |
| 多个护士 | 所有选中护士的排班（并集） | 选护士A+B → 显示护士A和B的所有排班 |
| 多个房间 | 所有选中房间的排班（并集） | 选VIP室1+2 → 显示VIP室1和2的所有排班 |

## ⚡ 快捷操作

| 操作 | 方法 | 效果 |
|------|------|------|
| 应用筛选 | 勾选复选框 | 立即更新显示 |
| 清除筛选 | 点击"清除"按钮 | 恢复显示所有资源 |
| 多选资源 | 勾选多个复选框 | 显示所有选中资源 |
| 查看状态 | 查看顶部提示 | 了解当前筛选条件 |

## 🔍 常用场景

### 场景1：查看护士工作量
```
操作：勾选护士A
结果：只显示护士A的所有排班
用途：检查工作量、安排新排班
```

### 场景2：查看房间使用率
```
操作：勾选VIP室1
结果：只显示VIP室1的所有排班
用途：检查使用率、查找空闲时段
```

### 场景3：查看特定配对
```
操作：勾选护士A + VIP室1
结果：只显示护士A在VIP室1的排班
用途：检查特定配对、优化组合
```

### 场景4：对比工作量
```
操作：勾选护士A + 护士B
结果：并排显示两位护士的排班
用途：对比工作量、平衡分配
```

## 💡 使用技巧

### 技巧1：先全局后细节
```
1. 默认查看全部（全局视图）
2. 发现目标资源
3. 应用筛选（细节视图）
4. 清除筛选（回到全局）
```

### 技巧2：逐步缩小范围
```
1. 先选护士（看所有排班）
2. 再选房间（缩小到特定房间）
3. 得到精确结果
```

### 技巧3：快速巡检
```
1. 勾选护士A → 查看 → 清除
2. 勾选护士B → 查看 → 清除
3. 勾选护士C → 查看 → 清除
```

## ⚠️ 注意事项

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| 看不到其他资源 | 正常现象 | 点击"清除"恢复 |
| 筛选结果为空 | 没有匹配的排班 | 检查筛选条件 |
| 忘记清除筛选 | 习惯问题 | 注意顶部提示 |

## 📞 快速帮助

### Q: 如何恢复显示所有资源？
**A**: 点击"清除"按钮

### Q: 为什么看不到其他资源？
**A**: 这是严格筛选的特点，点击"清除"即可

### Q: 筛选会影响数据吗？
**A**: 不会，只改变显示

### Q: 筛选条件会保存吗？
**A**: 不会，刷新后恢复默认
