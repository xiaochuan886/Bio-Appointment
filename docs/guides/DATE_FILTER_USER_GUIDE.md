# 📅 日期筛选器使用指南

## 快速开始

Bio-Appointment智能预约调度系统现在支持三种独立的日期筛选模式，让您可以轻松查看不同时间范围的排班数据。

## 三种视图模式

### 📆 日视图 - 查看单日排班

**适用场景**：查看具体某一天的详细排班安排

#### 如何使用
1. 点击顶部的"日视图"按钮
2. 点击日期选择器（显示如"11月28日"）
3. 在日历中选择具体日期
4. 系统自动显示该日期的所有排班

#### 快速操作
- **上一天**：点击左箭头 ◀
- **下一天**：点击右箭头 ▶
- **回到今天**：点击"今天"按钮

#### 显示示例
```
2025年11月28日 星期四
[◀] [📅 11月28日] [▶] [今天]
```

---

### 📅 周视图 - 查看整周排班

**适用场景**：查看一周（周一到周日）的完整排班情况

#### 如何使用
1. 点击顶部的"周视图"按钮
2. 点击周选择器（显示如"第48周"）
3. 在日历中点击任意日期
4. 系统自动显示该日期所在周的所有排班

#### 快速操作
- **上一周**：点击左箭头 ◀
- **下一周**：点击右箭头 ▶
- **回到本周**：点击"今天"按钮

#### 显示示例
```
第48周（11月24日 - 11月30日）
[◀] [📅 第48周] [▶] [今天]
```

#### 💡 提示
- 周定义：周一为一周的开始，周日为一周的结束
- 时间范围会清晰显示，如"11月24日 - 11月30日"
- 点击日历中任意日期，会自动选择该日期所在的整周

---

### 📊 月视图 - 查看整月排班

**适用场景**：查看一个月（1日到月末）的完整排班分布

#### 如何使用
1. 点击顶部的"月视图"按钮
2. 点击月份选择器（显示如"2025年11月"）
3. 在下拉框中选择年份和月份
4. 系统自动显示该月的所有排班

#### 快速操作
- **上一月**：点击左箭头 ◀
- **下一月**：点击右箭头 ▶
- **回到本月**：点击"今天"按钮

#### 显示示例
```
2025年11月
[◀] [📅 2025年11月] [▶] [今天]
```

#### 💡 提示
- 自动处理大小月（28/29/30/31天）
- 自动处理闰年的2月
- 显示从1日到月末的所有排班数据

## 常见使用场景

### 场景1：查看今天的排班
1. 确保在"日视图"模式
2. 点击"今天"按钮
3. 查看今天的详细排班

### 场景2：查看本周的排班
1. 切换到"周视图"模式
2. 点击"今天"按钮（如果不在本周）
3. 查看本周（周一到周日）的完整排班

### 场景3：查看下周的排班
1. 在"周视图"模式下
2. 点击右箭头 ▶
3. 查看下周的完整排班

### 场景4：查看本月的排班
1. 切换到"月视图"模式
2. 点击"今天"按钮（如果不在本月）
3. 查看本月（1日到月末）的完整排班

### 场景5：查看特定日期的排班
1. 切换到"日视图"模式
2. 点击日期选择器
3. 在日历中选择目标日期
4. 查看该日期的详细排班

### 场景6：对比不同周的排班
1. 切换到"周视图"模式
2. 使用左右箭头快速切换不同的周
3. 对比不同周的排班情况

### 控件说明

- **时间范围提示**：显示当前查看的时间范围
- **左箭头 ◀**：切换到上一个时间段
- **日期选择器 📅**：点击打开日期选择面板
- **右箭头 ▶**：切换到下一个时间段
- **今天按钮**：快速回到当前日期

## 快捷操作技巧

### 技巧1：快速浏览
使用左右箭头快速浏览不同时间段的排班，无需打开日期选择器。

### 技巧2：视图切换
在不同视图之间切换时，系统会保持当前选中的日期，自动显示对应时间范围的数据。

### 技巧3：回到今天
无论在哪个时间段，点击"今天"按钮都能快速回到当前日期。

### 技巧4：周视图选择
在周视图下，点击日历中任意日期，系统会自动选择该日期所在的整周，非常方便。

### 技巧5：月视图选择
在月视图下，使用年份和月份下拉框，可以快速跳转到任意月份。

## 常见问题

### Q1：为什么周视图显示的是周一到周日？
**A**：系统采用国际标准，以周一作为一周的开始。这样更符合工作日的习惯。

### Q2：如何查看跨月的周？
**A**：在周视图下，如果某周跨越两个月（如11月30日到12月6日），系统会正确显示该周的所有数据，包括两个月的排班。

### Q3：月视图会显示多少天的数据？
**A**：月视图会根据实际月份显示对应的天数：
- 1月、3月、5月、7月、8月、10月、12月：31天
- 4月、6月、9月、11月：30天
- 2月：28天（闰年29天）

### Q4：切换视图后，日期会改变吗？
**A**：不会。切换视图时，系统会保持当前选中的日期，只是显示的时间范围会根据视图模式自动调整。

### Q5：如何知道当前查看的是哪个时间段？
**A**：顶部会清晰显示时间范围提示：
- 日视图：`2025年11月28日 星期四`
- 周视图：`第48周（11月24日 - 11月30日）`
- 月视图：`2025年11月`
