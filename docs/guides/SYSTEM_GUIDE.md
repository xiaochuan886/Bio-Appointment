# Bio-Appointment智能预约调度系统 - 使用指南

## 系统概述

Bio-Appointment是一个专为医疗健康服务设计的智能预约调度系统，支持多角色协同工作，实现高效的资源管理和预约调度。

## 系统特色

### 🎨 设计风格
- **医疗蓝 + 清新绿**配色方案，专业且友好
- **响应式设计**，支持桌面和移动设备
- **直观的甘特图**可视化排班界面
- **状态色彩区分**，一目了然

### 🚀 核心功能

#### 1. 智能预约管理
- 自动计算人数和预估时长
- 实时资源可用性查询
- 急单特殊处理通道
- 同行客户支持

#### 2. 可视化排班
- 甘特图展示资源占用情况
- 拖拽式操作（点击编辑）
- 智能时长调整
- 资源冲突检测

#### 3. 多角色协同
- **销售端**：发起预约申请
- **护士长端**：智能排班调度
- **护士端**：任务执行管理
- **医生端**：预约确认握手

#### 4. 完整状态流转
- 待排班 → 已排班 → 已确认 → 进行中 → 已完成
- 每个状态都有明确的操作权限
- 超时自动提醒和备注要求

## 角色功能详解

### 👔 销售端 - 预约发起

**访问路径**：工作台 → 预约发起

**主要功能**：
1. **客户信息录入**
   - 填写主客户姓名（必填）
   - 添加同行客户（可选，支持多人）
   - 系统自动计算总人数

2. **服务项目选择**
   - 选择服务类型（护理/面诊/报告解读）
   - 查看标准预估时长
   - 了解是否需要医生确认

3. **时间段选择**
   - 选择预约日期
   - 查看可用时间段（绿色表示可用）
   - 急单模式（选择今天自动触发）

4. **急单处理**
   - 选择日期为今天时，自动标记为急单
   - 仅允许预约护理类服务
   - 护士长端会收到特殊提示

**操作提示**：
- 根据填写的客户姓名与同行姓名自动计算人数
- 灰色区域为资源已满，绿色为可用时段
- 提交后等待护士长确认排班

### 👩‍⚕️ 护士长端 - 智能排班

**访问路径**：工作台 → 智能排班

**主要功能**：
1. **排班看板**
   - 甘特图展示房间和护士的排班情况
   - 时间轴：08:00 - 18:00
   - 颜色标识：🔥急单 🟨待排班 🟦已排班 🟩已锁定

2. **待排班列表**
   - 查看所有待处理的预约申请
   - 急单优先显示在顶部
   - 显示客户信息和预估时长

3. **资源分配**
   - 选择房间（VIP室1-5、治疗区A-C）
   - 分配护士
   - 调整时间段
   - 修改预估时长（可选）

4. **时长干预**
   - 根据客户画像调整时长
   - 填写调整原因
   - 系统实时校验时间冲突

5. **发布排班**
   - 点击"创建排班"保存草稿
   - 确认无误后可锁定排班
   - 锁定后通知相关人员

**操作提示**：
- 点击甘特图上的任务卡片可以编辑排班
- 急单会以红色高亮显示
- 建议根据历史数据调整时长

### 👨‍⚕️ 医生端 - 预约待办

**访问路径**：工作台 → 预约待办

**主要功能**：
1. **待确认列表**
   - 查看需要医生确认的预约
   - 显示客户信息和服务详情
   - 查看销售人员信息

2. **预约握手**
   - **接受**：确认预约，进入排班流程
   - **拒绝**：拒绝预约，需填写原因

3. **拒绝处理**
   - 必须填写拒绝原因
   - 可选择建议改期日期
   - 系统自动通知销售人员

4. **历史记录**
   - 查看已接受的预约
   - 查看已拒绝的预约及原因

**操作提示**：
- 及时处理待确认预约，避免影响排班
- 拒绝时请提供详细原因或建议时间
- 已接受的预约会进入护士长排班流程

### 👩‍⚕️ 护士端 - 我的任务

**访问路径**：工作台 → 我的任务

**主要功能**：
1. **任务概览**
   - 待执行任务数量
   - 进行中任务数量
   - 已完成任务数量

2. **任务执行流程**
   - **客户到达**：点击"客户到达"按钮
   - **开始服务**：自动记录开始时间
   - **完成服务**：点击"完成服务"按钮

3. **超时处理**
   - 系统自动计算实际执行时长
   - 超过预约时间20%需填写备注
   - 强制填写超时原因

4. **任务详情**
   - 查看客户姓名和服务项目
   - 查看分配的房间
   - 查看预估时长和实际时长

**操作提示**：
- 任务按状态分组显示
- 进行中的任务会高亮显示
- 完成服务时如有超时请详细说明原因

## 状态流转说明

### 预约状态流转
```
待排班 (pending)
  ↓ 护士长创建排班
已排班 (scheduled)
  ↓ 医生确认（如需要）
已确认 (confirmed)
  ↓ 护士点击"客户到达"
进行中 (in_progress)
  ↓ 护士点击"完成服务"
已完成 (completed)
```

### 排班状态流转
```
草稿 (draft)
  ↓ 护士长确认发布
已发布 (published)
  ↓ 护士长锁定
已锁定 (locked)
```

### 医生确认状态
```
待确认 (pending)
  ↓ 医生操作
已接受 (accepted) / 已拒绝 (rejected)
```

## 特殊场景处理

### 急单流程
1. 销售选择日期为"今天"
2. 系统自动标记为急单
3. 仅允许选择护理类服务
4. 护士长端急单优先显示
5. 甘特图上以红色高亮

### 资源冲突
- 系统自动检测资源占用情况
- 时间段冲突时无法创建排班
- 建议选择其他时间或资源

### 护士请假
- 护士长可将护士状态设为"不可用"
- 系统自动筛选受影响的预约
- 需要重新分配资源

### 超时处理
- 实际时长超过预约时间20%
- 护士必须填写超时备注
- 记录用于后续时长优化

## 常见问题

**Q: 如何修改已创建的排班？**
A: 在护士长端的甘特图上点击对应的任务卡片，即可编辑排班信息。

**Q: 急单可以预约所有服务吗？**
A: 不可以。急单（当天预约）仅允许预约护理类服务，其他服务请选择明日或之后的日期。

**Q: 如何查看历史预约记录？**
A: 目前系统主要展示当前和未来的预约。历史记录功能可在后续版本中添加。

**Q: 可以同时为多个客户预约吗？**
A: 可以。在预约发起页面，可以添加多个同行客户，系统会自动计算总人数。

**Q: 如何处理预约取消？**
A: 医生可以拒绝预约，护士长可以删除排班。取消的预约状态会变为"已取消"。
