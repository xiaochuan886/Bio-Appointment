原来的 `start.sh` 脚本缺少 **API 服务器** 的启动，导致前端无法访问后端接口。

   - `./start.sh status` 现在会显示 API 服务器状态
   - 检查进程、端口占用、健康状态

4. ✅ **完整停止**
   - `./start.sh stop` 现在会同时停止 API 服务器和数据库

## ⚠️ 常见问题

### 1. 端口被占用

**问题**: `EADDRINUSE: address already in use :::3001`

**解决**:
```bash
# 查找占用进程
lsof -ti:3001

# 终止进程
lsof -ti:3001 | xargs kill -9

# 或者直接停止 API 服务器
pkill -f "node server/api-server.cjs"
```

### 2. API 服务器启动失败

**查看日志**:
```bash
tail -50 /tmp/api-server.log
```

常见原因：
- 数据库连接失败（检查 PostgreSQL 是否运行）
- 端口被占用（使用上面的命令释放端口）
- 代码错误（查看日志中的错误信息）

### 3. 前端无法连接 API

**检查步骤**:
```bash
# 1. 检查 API 服务器是否运行
./start.sh status

# 2. 测试 API 端点
curl http://localhost:3001/api/health

# 3. 重启 API 服务器
pkill -f "node server/api-server.cjs"
nohup node server/api-server.cjs > /tmp/api-server.log 2>&1 &
```
