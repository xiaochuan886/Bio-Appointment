# 智能排班功能快速参考

## 🎯 核心功能

### 1. 资源冲突检测
**触发时机**: 创建或编辑排班时  
**检测内容**: 房间冲突 + 护士冲突  
**操作选项**: 取消排班 | 强制排班

### 2. 分行显示
**触发条件**: 同一资源有多个重叠排班  
**显示效果**: 自动分行,不重叠  
**视觉提示**: ⚠️ X个重叠排班

### 3. 视图切换
**视图类型**: 日视图 | 周视图 | 月视图  
**切换位置**: 资源看板右上角  
**当前状态**: 日视图完整 | 周/月视图UI就绪

## 🔧 关键函数

### 冲突检测
```typescript
detectResourceConflicts(
  existingSchedules,  // 现有排班
  newSchedule,        // 新排班
  excludeScheduleId   // 排除的排班ID(编辑时)
)
```

### 时间重叠检测
```typescript
isTimeOverlap(
  start1, end1,  // 时间段1
  start2, end2   // 时间段2
)
```

### 分行布局
```typescript
arrangeSchedulesInRows(
  schedules  // 排班列表
)
```

## 🐛 故障排查

### 问题: 冲突检测不生效
**检查**: 
- schedules数据是否正确加载
- 时间格式是否正确(HH:mm:ss)

### 问题: 分行显示异常
**检查**:
- 是否有时间重叠
- 行高计算是否正确

### 问题: 视图切换无响应
**检查**:
- viewMode状态是否更新
- GanttChart是否接收到新的viewMode

## 💡 最佳实践

### 创建排班
1. 先选择日期
2. 再选择待排班预约
3. 填写资源和时间
4. 注意冲突提示

### 处理冲突
1. 仔细查看冲突信息
2. 评估是否需要强制排班
3. 如强制排班,线下协调资源

### 查看排班
1. 使用日视图查看详细信息
2. 使用周视图(待实现)查看概览
3. 注意重叠排班提示
