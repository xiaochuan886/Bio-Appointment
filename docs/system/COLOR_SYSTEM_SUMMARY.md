## 🎨 设计亮点

### 1. 颜色分离策略

**护士（暖色调）**：
- 珊瑚橙、薰衣草紫、天空蓝、翡翠绿、阳光黄
- 玫瑰粉、青柠绿、深紫罗兰、橙红色、青色

**房间（冷色调）**：
- 深海蓝、森林绿、石板灰、深紫色、深青色
- 橄榄绿、深棕色、靛蓝色、深粉色、深灰色

**优势**：
- 一眼就能区分护士和房间
- 暖色调给人亲切感，适合护士
- 冷色调给人专业感，适合房间

### 2. 渐变色组合

**实现方式**：
```css
background: linear-gradient(135deg, 
  护士颜色 0%, 
  护士颜色 50%, 
  房间颜色 50%, 
  房间颜色 100%
);
```

**优势**：
- 同时展示护士和房间信息
- 视觉效果美观
- 易于识别配对关系

### 3. 状态叠加

**优先级**：
1. 急单（红色边框）- 最高优先级
2. 已锁定（绿色边框）- 次优先级
3. 筛选高亮（黄色光环）- 辅助标识

**优势**：
- 清晰的视觉层级
- 快速识别重要信息
- 不影响颜色编码系统

### 4. 无障碍设计

**色盲支持**：
- 每个资源都有独特的图案纹理
- 高对比度文字（白色 + 阴影）
- 边框和光环提供额外区分

**屏幕阅读器**：
- 适当的ARIA标签
- 语义化HTML结构
- 工具提示可访问

## 📞 支持与反馈

### 常见问题

**Q: 如何添加新的护士或房间？**
A: 系统会自动循环使用预定义的颜色方案，无需手动配置。

**Q: 颜色会重复吗？**
A: 超过10个资源时会重复，但通过索引取模确保同时在岗的资源颜色不重复。

**Q: 如何支持色盲用户？**
A: 每个资源都有独特的图案纹理，配合高对比度文字和边框。

**Q: 可以自定义颜色吗？**
A: 当前版本不支持，但已列入未来计划。
