## 新增功能

### 1. 资源冲突二次确认 ✨

#### 功能描述
护士长在创建或编辑排班时,系统会自动检测资源冲突(房间冲突和护士冲突)。如果检测到冲突,会弹出确认对话框,显示详细的冲突信息,让护士长决定是否强制排班。

#### 业务价值
- **避免资源冲突**: 自动检测并提示资源冲突,减少人为错误
- **灵活应对急单**: 支持强制排班,满足急单或特殊情况的需求
- **提升决策质量**: 提供详细的冲突信息,帮助护士长做出明智决策

#### 技术实现
- 精确的时间重叠检测算法
- 实时资源可用性校验
- 友好的冲突信息展示

---

### 2. 甘特图重叠资源分行显示 📊

#### 功能描述
当同一资源(房间或护士)在同一时间段有多个排班时,甘特图会自动将这些排班分配到不同的行显示,而不是重叠在一起。

#### 业务价值
- **清晰可视化**: 所有排班一目了然,避免视觉混乱
- **快速识别冲突**: 重叠排班数量一目了然
- **提升管理效率**: 护士长可以快速了解资源使用情况

#### 技术实现
- 智能分行布局算法
- 动态行高调整
- 醒目的重叠数量提示

---

### 3. 多视图支持(日/周/月) 📅

#### 功能描述
资源看板新增视图切换功能,支持日视图、周视图和月视图三种模式,满足不同的管理需求。

#### 业务价值
- **灵活的视角**: 根据需要切换不同的时间维度
- **长期规划**: 周视图和月视图支持长期排班规划
- **提升效率**: 快速切换视图,无需重新加载页面

#### 技术实现
- 视图切换器组件
- 视图状态管理
- 扩展性设计(为周视图和月视图预留接口)

## 核心算法

### 时间重叠检测算法
```typescript
function isTimeOverlap(start1, end1, start2, end2) {
  // 将时间转换为分钟数
  const start1Minutes = hour1 * 60 + minute1;
  const end1Minutes = hour2 * 60 + minute2;
  const start2Minutes = hour3 * 60 + minute3;
  const end2Minutes = hour4 * 60 + minute4;
  
  // 检测重叠
  return start1Minutes < end2Minutes && start2Minutes < end1Minutes;
}
```

**算法特点:**
- 精确到分钟级别
- 支持各种重叠情况(完全重叠、部分重叠、包含关系等)
- 时间复杂度: O(1)

### 分行布局算法
```typescript
function arrangeSchedulesInRows(schedules) {
  const rows = [];
  
  schedules.forEach(schedule => {
    // 尝试将排班放入现有行
    let placed = false;
    for (const row of rows) {
      const hasOverlap = row.some(existing => 
        isTimeOverlap(schedule.start, schedule.end, existing.start, existing.end)
      );
      
      if (!hasOverlap) {
        row.push(schedule);
        placed = true;
        break;
      }
    }
    
    // 如果无法放入现有行,创建新行
    if (!placed) {
      rows.push([schedule]);
    }
  });
  
  return rows;
}
```

**算法特点:**
- 贪心算法,优先填充现有行
- 最小化行数
- 时间复杂度: O(n²),n为排班数量
