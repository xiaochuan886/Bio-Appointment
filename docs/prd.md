# Bio-Appointment智能预约调度系统需求文档

## 1. 系统概述

### 1.1 系统名称
Bio-Appointment智能预约调度系统
\n### 1.2 系统描述
独立的预约调度系统，为医疗健康服务提供智能化预约和排班管理，支持多端协同工作，内置完善的用户身份认证与权限管理体系。

### 1.3 涉及端口
- Sales App（销售端）\n- Pad/PC（护士长端）
- Pad（护士端）
- Doctor App（医生端）
- Admin（系统管理员端）

## 2. 全局逻辑与算法

### 2.1 动态时长计算模型
- **标准预估时长（T_base）**：采用〖标准预估+护士长修正〗双层时长模型\n- **实际执行时长（T_actual）**：护士长可根据客户画像和历史数据手动调整
- **资源占用权重**：排班资源占用以T_actual为准

### 2.2 资源可用性校验
- **可用性公式**：Available(t) = (Rooms(t) ≥ 1) ∧ (Nurses(t) ≥ 1)\n- **急单模式**：若为〖急单〗模式，忽略资源校验，强制允许提交
\n### 2.3 资源锁定状态机
- **软锁定（Soft Lock）**：销售提交预约，扣减库存，允许护士长挪动
- **硬锁定（Hard Lock）**：护士长确认排班，资源被实名占用，不可被系统自动算法覆盖

## 3. 用户管理与权限控制

### 3.1 系统角色定义
\n#### [ROLE-01] 超级管理员（Super Admin）
- **核心职责**：系统最高权限拥有者，负责整体系统管理和核心配置
- **权限范围**：\n  - 用户管理：创建、编辑、删除所有用户账户
  - 角色管理：创建、编辑、删除所有角色及权限配置
  - 系统配置：管理员工、房间、设备等基础资源
  - 数据管理：访问和导出所有业务数据
  - 日志审计：查看所有用户操作日志和系统日志

#### [ROLE-02] 普通管理员（Admin）\n- **核心职责**：协助超级管理员进行日常系统管理和资源配置
- **权限范围**：
  - 用户管理：创建、编辑普通用户（销售、护士、医生）账户，但无法操作管理员账户
  - 资源配置：管理员工信息、房间信息、设备配置\n  - 数据查看：查看业务数据和报表，但不能删除核心数据
  - 无权限操作角色权限配置和系统核心参数

#### [ROLE-03] 销售/健康管理师（Sales）
- **核心职责**：发起预约申请，管理客户信息\n- **权限范围**：
  - 预约管理：创建、查看、编辑自己发起的预约
  - 客户管理：填写客户姓名、同行客户信息
  - 时间查询：查询可用时间段和资源状态
  - 无权限访问他人预约详情、资源配置、排班调度功能

#### [ROLE-04] 护士长（Head Nurse）
- **核心职责**：调度指挥，确认排班，分配医疗资源
- **权限范围**：
  - 排班管理：查看所有待排班预约，调整时长，分配房间和护士
  - 资源调度：拖拽任务卡片，确认发布排班\n  - 客户画像：查看客户历史数据和预估耗时
  - 急单处理：处理急单预约，协调资源冲突
  - 无权限修改系统配置和用户权限

#### [ROLE-05] 护士（Nurse）
- **核心职责**：执行服务任务，更新任务状态
- **权限范围**：
  - 任务执行：查看分配给自己的任务列表\n  - 状态更新：Check-in、Start、Finish任务状态流转
  - 超时反馈：填写任务超时备注
  - 无权限查看他人任务、修改排班、访问系统配置

#### [ROLE-06] 医生（Doctor）
- **核心职责**：处理面诊和报告解读预约申请
- **权限范围**：
  - 预约处理：接受、拒绝、改期面诊/报告解读申请
  - 时间建议：拒绝或改期时填写建议时间
  - 查看申请：查看销售发起的医生服务申请
  - 无权限访问护理服务预约、资源配置、用户管理

### 3.2 权限控制粒度

#### [PERM-01] 模块级权限\n- **用户管理模块**：超级管理员、普通管理员\n- **预约发起模块**：销售/健康管理师\n- **智能排班模块**：护士长\n- **任务执行模块**：护士
- **医生协同模块**：医生\n- **系统配置模块**：超级管理员、普通管理员
- **数据报表模块**：超级管理员、普通管理员、护士长

#### [PERM-02] 操作级权限
- **增（Create）**：根据角色限制创建权限，如销售仅能创建预约，管理员能创建用户
- **删（Delete）**：仅超级管理员可删除核心数据，普通管理员和护士长仅能删除自己创建的非核心数据
- **改（Update）**：护士长可修改排班，销售可修改自己发起的预约，护士仅能更新任务状态
- **查（Read）**：销售查看自己的预约，护士查看自己的任务，护士长和管理员查看全部数据
- **审核（Approve）**：护士长确认排班，医生接受/拒绝预约申请\n- **导出（Export）**：超级管理员和普通管理员可导出数据报表

#### [PERM-03] 数据级权限
- **个人数据**：销售仅能访问自己发起的预约，护士仅能访问分配给自己的任务\n- **部门数据**：护士长可访问所有护理服务相关的预约和排班数据
- **全局数据**：超级管理员和普通管理员可访问所有业务数据
- **敏感数据**：用户密码加密存储，仅用户本人和超级管理员可重置密码

### 3.3 用户管理功能

#### [USER-01] 用户注册与登录
- **注册方式**：\n  - 管理员创建：超级管理员和普通管理员在后台创建用户账户，设置初始密码
  - 自主注册（可选）：普通用户通过注册页面填写基本信息，管理员审核后激活账户
- **登录方式**：\n  - 用户名+密码登录\n  - 支持〖记住我〗功能，7天内免登录
  - 登录失败3次后，账户锁定15分钟
\n#### [USER-02] 角色分配
- **单角色分配**：每个用户账户仅能分配一个主要角色（销售、护士、医生、护士长、管理员）
- **角色变更**：管理员可修改用户角色，变更后立即生效
- **权限继承**：用户登录后，系统根据角色自动加载对应权限和功能菜单

#### [USER-03] 用户信息管理
- **基本信息**：
  - 用户名（唯一，不可重复）
  - 真实姓名
  -邮箱（用于密码找回和通知）
  - 联系电话
  - 所属部门（销售部、护理部、医疗部、管理部）
- **权限信息**：\n  - 当前角色\n  - 账户状态（启用/禁用）
  - 创建时间
  - 最后登录时间
- **信息编辑**：
  - 用户可自行修改邮箱、联系电话\n  - 管理员可修改用户的所有信息和角色

#### [USER-04] 用户状态管理
- **启用状态**：用户可正常登录和使用系统
- **禁用状态**：用户无法登录，已有会话立即失效
- **离职处理**：管理员将用户状态设为〖离职〗，该用户的历史数据保留但账户永久禁用

### 3.4 认证与安全要求

#### [SEC-01] 密码安全策略
- **密码存储**：采用bcrypt加密算法，加盐哈希存储，禁止明文存储
- **密码强度**：\n  - 最小长度8位
  - 必须包含大写字母、小写字母、数字、特殊字符中的至少3种
- **密码重置**：
  - 用户可通过邮箱验证码自行重置密码
  - 管理员可强制重置用户密码，用户首次登录后必须修改密码
\n#### [SEC-02] 会话管理
- **Token机制**：登录后生成JWT Token，有效期2小时
- **自动续期**：用户活跃操作时自动续期Token，避免频繁登录
- **强制登出**：管理员禁用用户账户时，系统强制清除该用户的所有会话\n
#### [SEC-03] 登录安全措施
- **登录尝试限制**：同一账户连续失败3次后锁定15分钟，防止暴力破解\n- **异常登录检测**：记录用户登录IP和设备信息，异常登录时发送邮件通知
- **操作日志**：记录所有用户的登录、登出、关键操作日志，便于审计追溯

### 3.5 前端界面要求

#### [UI-01] 用户列表管理界面
- **列表展示**：
  - 表格形式展示所有用户，包含用户名、真实姓名、角色、部门、状态、最后登录时间\n  - 支持按角色、部门、状态筛选
  - 支持按用户名、真实姓名搜索
- **操作按钮**：
  - 新增用户：打开用户创建表单
  - 编辑用户：打开用户编辑表单
  - 禁用/启用：一键切换用户状态
  - 重置密码：管理员强制重置用户密码\n  - 删除用户：超级管理员可删除用户（需二次确认）
\n#### [UI-02] 角色权限配置界面
- **角色列表**：展示所有系统角色及其权限范围
- **权限矩阵**：
  - 表格形式展示〖角色 vs 功能模块〗的权限关系
  - 支持勾选/取消勾选调整权限
- **保存生效**：点击〖保存〗后，权限配置立即生效，已登录用户下次操作时自动更新权限

#### [UI-03] 动态菜单与功能显示
- **菜单栏**：
  - 用户登录后，系统根据角色动态生成功能菜单
  - 销售端仅显示〖预约发起〗模块
  - 护士长端显示〖智能排班〗〖预约待办〗模块
  - 护士端显示〖我的任务〗模块
  - 医生端显示〖预约握手〗模块
  - 管理员端显示〖用户管理〗〖系统配置〗〖数据报表〗模块\n- **功能按钮**：
  - 根据操作级权限动态显示/隐藏按钮（如无删除权限则不显示删除按钮）
  - 无权限操作时，按钮置灰并提示〖您无权限执行此操作〗
\n#### [UI-04] 个人中心界面
- **信息展示**：
  - 显示用户头像、用户名、真实姓名、角色、部门\n  - 显示最后登录时间和登录IP
- **信息编辑**：
  - 用户可修改邮箱、联系电话
  - 用户可修改密码（需输入旧密码验证）
- **登出按钮**：点击后清除会话并跳转至登录页

## 4. 角色权限与业务流程

### 4.1 总体业务流程
\n**健康管理师/销售端流程：**

1. **登录系统**
   - 输入用户名和密码登录
   - 系统验证身份并加载销售端功能菜单

2. **填写客户姓名**
   - 主客户姓名（必填）
   - 同行客户姓名（可选，多人）
   - 系统自动计算总人数N_pax

3. **选择服务场景**
   - **场景A：护理服务**
     - 选择日期（今天/未来日期）
     - 选择服务项目\n     - 输入服务+姓名列表
     - 系统计算Test\n     - 查询资源\n     - 选择时段
     - 提交预占用\n   - **场景B：面诊/报告**
     - 选择医生
     - 选择排班时段
     - 提交医生确认
\n4. **急单流程**
   - 选择日期为今天
   - 仅限抽血服务
   - 跳过资源校验
   - 单据标记为URGENT
   - 护士长端强提醒
\n**护士长端调度流程：**
\n1. **登录系统**
   - 输入用户名和密码登录
   - 系统验证身份并加载护士长端功能菜单

2. **查看客户画像**
   - 智能计算客户信息
   - 显示历史预约数据
\n3. **评估耗时**
   - 根据客户画像和历史数据评估实际耗时
\n4. **调整时长**
   - 手动修正为T_actual实际时长
   - 系统实时校验甘特图冲突

5. **分配资源**
   - 绑定房间+护士
   - 支持拖拽任务卡片进行资源分配

6. **确认发布**
   - 向Sales推送最终确定的时间段
   - 通知各方\n
**医生端处理流程：**
\n1. **登录系统**
   - 输入用户名和密码登录
   - 系统验证身份并加载医生端功能菜单

2. **接收预约申请**
   - 查看销售发起的面诊/解读申请
\n3. **处理申请**
   - 接受/拒绝/改期\n   - 拒绝/改期时必须填写〖建议时间〗\n\n**执行端流程：**

1. **登录系统**
   - 输入用户名和密码登录\n   - 系统验证身份并加载护士端功能菜单\n
2. **任务执行**
   - Check-in（客户到达）
   - Start（开始服务）
   - Finish（服务结束）
\n3. **状态流转**
   - 我的任务列表
   - 超时反馈机制
\n**系统管理员配置流程：**
\n1. **登录系统**
   - 输入管理员用户名和密码登录
   - 系统验证身份并加载管理端功能菜单

2. **用户管理**
   - 创建新用户账户
   - 分配角色和权限
   - 启用/禁用用户账户
   - 重置用户密码

3. **员工管理**
   - 添加/编辑/删除护士信息
   - 设置员工工作时间
   - 配置员工技能标签

4. **房间管理**
   - 添加/编辑/删除房间信息
   - 设置房间类型（VIP室、治疗区等）
   - 配置房间容量和设备信息

5. **资源配置**
   - 管理各类医疗设备
   - 设置设备使用限制和兼容性
   - 配置资源维护计划

### 4.2 流程图说明
根据提供的流程图，系统业务流程分为三大主线：

- **护理服务预约流程**：用户登录 → 客户姓名输入 → 场景选择 → 日期检查 → 资源查询 → 时间选择 → 提交预约 → 护士长确认排班 → 通知各方\n- **医生面诊预约流程**：用户登录 → 客户姓名输入 → 场景选择 → 医生选择 → 时间选择 → 提交医生确认 → 医生处理 → 通知各方
- **系统配置流程**：管理员登录 → 用户管理 → 资源配置 → 员工管理 → 数据保存 → 生效通知

### 4.3 特殊场景处理
- **急单处理**：选择日期为今天时，仅允许预约抽血服务，系统自动进入急单模式
- **同行客户**：支持多人同行预约，系统自动计算总人数并调整预估时长
- **医生确认**：面诊/报告类服务需要医生端确认后才能完成预约流程
- **资源初始化**：系统启动时需完成基础员工和房间配置才能进行正常预约
- **权限验证**：所有操作前均需验证用户权限，无权限操作自动拦截并提示

## 5. 功能模块详述

### 5.1 预约发起端（健康管理师/销售）

#### [HM-01] 客户姓名输入
- **功能逻辑**：直接填写客户姓名，支持同行客户姓名输入，系统自动计算人数N_pax
- **输入方式**：主客户姓名（必填）+同行客户姓名（可选，多人）
- **自动计算**：N_pax = 1 + N_companions
- **权限校验**：仅销售/健康管理师角色可访问
\n#### [HM-02] 服务场景选择
- **护理服务**：基础回输、静脉采血等护理项目
- **面诊/报告**：医生面诊、报告深度解读等医疗服务
- **场景分流逻辑**：根据选择的服务类型进入不同预约流程
- **权限校验**：仅销售/健康管理师角色可访问

#### [HM-03] 时间选择与预约提交
- **普通预约**：选择预约日期 → 查询可用时间段 → 选择时段 → 提交预约\n- **急单预约**：选择今天日期 → 自动进入急单流程 → 跳过资源校验 → 提交急单
- **医生面诊**：选择医生 → 选择排班时段 → 提交医生确认
- **权限校验**：仅销售/健康管理师角色可提交预约

### 5.2 调度指挥端（护士长）\n
#### [HN-01] 智能排班看板
- **操作方式**：支持拖拽任务卡片到不同的房间/护士行\n- **图例标识**：🟥急单 🟨待排班 🟩已确认 ⬜空闲
- **纵轴**：资源组（VIP室1-5, 治疗区A-C, 护士A,护士B...）
- **横轴**：时间轴（08:00 - 18:00）
- **权限校验**：仅护士长角色可访问\n
#### [HN-01-A] 资源看板筛选功能
- **筛选目标**：\n  - 护士（包含所有层级的护士）
  - 护士长
  - 房间资源\n\n- **筛选器设计要求**：
  - **界面控件**：提供清晰的筛选器组件，支持下拉选择器、复选框组或搜索过滤栏
  - **多选支持**：允许用户同时选择〖护士/护士长〗和〖房间资源〗进行筛选，或仅选择其中一项\n  - **实时筛选**：当用户选择筛选条件后，资源看板视图实时刷新，仅显示符合条件的资源
  - **状态标识**：当前激活的筛选条件应有明确的视觉标识（如高亮、勾选状态等）

- **筛选逻辑**：
  - 用户选择〖护士（含护士长）〗时，看板显示所有护士和护士长资源的排班情况
  - 用户选择〖房间资源〗时，看板显示所有房间资源的排班情况
  - 用户同时勾选上述两个选项时，看板同时显示护士（含护士长）和房间资源的排班情况\n  - 支持筛选条件的清除和重置功能

- **交互设计**：
  - 筛选器位于资源看板顶部，与日期选择器、视图切换按钮并列
  - 筛选器默认状态为〖全部显示〗\n  - 点击筛选器后展开选项列表，支持多选复选框
  - 选择后立即生效，看板内容实时更新
  - 筛选器右侧显示当前筛选条件数量标识（如：已选2项）

- **权限校验**：仅护士长角色可使用筛选功能

#### [HN-02] 客户画像与时长干预
- **智能计算**：根据姓名列表自动计算N_pax，即时提示〖预计标准耗时：X小时〗
- **时长修正**：护士长可手动修改时长，系统实时校验新时长在甘特图上是否冲突
- **历史数据**：显示历史预约数据（如历史平均耗时）
- **权限校验**：仅护士长角色可修改时长

#### [HN-03] 资源分配与发布

- **权限校验**：仅护士长角色可确认发布
\n### 5.3 医生协同端（Doctor）

## 6. 异常场景处理

### 6.1 预约撞单\n- **处理方式**：数据库层采用乐观锁，后提交者提示〖该时段刚刚已被占用，请刷新重试〗
\n### 6.2 护士临时请假
- **处理**：护士长将该护士状态置为Unavailable，系统自动筛选受影响的未来预约
\n### 6.3 急单资源爆满
- **处理方式**：允许急单〖重叠排班〗，甘特图显示两张卡片层叠，护士长线下协调

### 6.4 资源配置异常
- **新系统启动**：提示必须配置基础员工和房间信息才能进行预约
- **资源不足**：预约时显示〖当前无可用资源，请联系管理员配置〗
- **配置冲突**：员工工作时间和房间使用时间冲突时系统自动提示

### 6.5 筛选功能异常
- **无匹配资源**：当筛选条件下无可用资源时，看板显示〖当前筛选条件下暂无资源〗
- **筛选器失效**：筛选器加载失败时，默认显示全部资源，并提示用户刷新页面
\n### 6.6 用户权限异常
- **无权限操作**：用户尝试访问无权限功能时，系统拦截并提示〖您无权限执行此操作，请联系管理员〗
- **会话过期**：Token过期后自动跳转至登录页，提示〖会话已过期，请重新登录〗
- **账户被禁用**：用户登录时若账户已被禁用，提示〖您的账户已被禁用，请联系管理员〗
- **密码错误次数过多**：连续失败3次后账户锁定15分钟，提示〖密码错误次数过多，账户已锁定15分钟〗
