# Bio-Appointment智能预约调度系统需求文档

## 1. 系统概述

### 1.1 系统名称
Bio-Appointment智能预约调度系统

### 1.2 系统描述
独立的预约调度系统，为医疗健康服务提供智能化预约和排班管理，支持多端协同工作。

### 1.3 涉及端口
- Sales App（销售端）
- Pad/PC（护士长端）
- Pad（护士端）
- Doctor App（医生端）

## 2. 全局逻辑与算法

### 2.1 动态时长计算模型
- **标准预估时长（T_base）**：采用"标准预估+护士长修正"双层时长模型
- **实际执行时长（T_actual）**：护士长可根据客户画像和历史数据手动调整
- **资源占用权重**：排班资源占用以T_actual为准

### 2.2 资源可用性校验
- **可用性公式**：Available(t) = (Rooms(t) ≥ 1) ∧ (Nurses(t) ≥ 1)
- **急单模式**：若为"急单"模式，忽略资源校验，强制允许提交

### 2.3 资源锁定状态机
- **软锁定（Soft Lock）**：销售提交预约，扣减库存，允许护士长挪动
- **硬锁定（Hard Lock）**：护士长确认排班，资源被实名占用，不可被系统自动算法覆盖

## 3. 角色权限与业务流程

### 3.1 总体业务流程

**健康管理师/销售端流程：**

1. **填写客户姓名**
   - 主客户姓名（必填）
   - 同行客户姓名（可选，多人）
   - 系统自动计算总人数N_pax

2. **选择服务场景**
   - **场景A：护理服务**
     - 选择日期（今天/未来日期）
     - 选择服务项目
     - 输入服务+姓名列表
     - 系统计算Test
     - 查询资源
     - 选择时段
     - 提交预占用
   - **场景B：面诊/报告**
     - 选择医生
     - 选择排班时段
     - 提交医生确认

3. **急单流程**
   - 选择日期为今天
   - 仅限抽血服务
   - 跳过资源校验
   - 单据标记为URGENT
   - 护士长端强提醒

**护士长端调度流程：**

1. **查看客户画像**
   - 智能计算客户信息
   - 显示历史预约数据

2. **评估耗时**
   - 根据客户画像和历史数据评估实际耗时

3. **调整时长**
   - 手动修正为T_actual实际时长
   - 系统实时校验甘特图冲突

4. **分配资源**
   - 绑定房间+护士\n   - 支持拖拽任务卡片进行资源分配

5. **确认发布**
   - 向Sales推送最终确定的时间段
   - 通知各方

**医生端处理流程：**

1. **接收预约申请**
   - 查看销售发起的面诊/解读申请

2. **处理申请**
   - 接受/拒绝/改期
   - 拒绝/改期时必须填写"建议时间"

**执行端流程：**

1. **任务执行**
   - Check-in（客户到达）
   - Start（开始服务）
   - Finish（服务结束）

2. **状态流转**
   - 我的任务列表
   - 超时反馈机制

### 3.2 流程图说明
根据提供的流程图，系统业务流程分为两大主线：

- **护理服务预约流程**：客户姓名输入 → 场景选择 → 日期检查 → 资源查询 → 时间选择 → 提交预约 → 护士长确认排班 → 通知各方
- **医生面诊预约流程**：客户姓名输入 → 场景选择 → 医生选择 → 时间选择 → 提交医生确认 → 医生处理 → 通知各方

### 3.3 特殊场景处理
- **急单处理**：选择日期为今天时，仅允许预约抽血服务，系统自动进入急单模式
- **同行客户**：支持多人同行预约，系统自动计算总人数并调整预估时长
- **医生确认**：面诊/报告类服务需要医生端确认后才能完成预约流程

## 4. 功能模块详述

### 4.1 预约发起端（健康管理师/销售）

#### [HM-01] 客户姓名输入
- **功能逻辑**：直接填写客户姓名，支持同行客户姓名输入，系统自动计算人数N_pax
- **输入方式**：主客户姓名（必填）+同行客户姓名（可选，多人）
- **自动计算**：N_pax = 1 + N_companions

#### [HM-02] 服务场景选择\n- **护理服务**：基础回输、静脉采血等护理项目
- **面诊/报告**：医生面诊、报告深度解读等医疗服务
- **场景分流逻辑**：根据选择的服务类型进入不同预约流程

#### [HM-03] 时间选择与预约提交
- **普通预约**：选择预约日期 → 查询可用时间段 → 选择时段 → 提交预约
- **急单预约**：选择今天日期 → 自动进入急单流程 → 跳过资源校验 → 提交急单
- **医生面诊**：选择医生 → 选择排班时段 → 提交医生确认

### 4.2 调度指挥端（护士长）

#### [HN-01] 智能排班看板
- **操作方式**：支持拖拽任务卡片到不同的房间/护士行
- **图例标识**：🟥急单 🟨待排班 🟩已确认 ⬜空闲
- **纵轴**：资源组（VIP室1-5, 治疗区A-C, 护士A, 护士B...）
- **横轴**：时间轴（08:00 - 18:00）

#### [HN-02] 客户画像与时长干预\n- **智能计算**：根据姓名列表自动计算N_pax，即时提示"预计标准耗时：X小时"
- **时长修正**：护士长可手动修改时长，系统实时校验新时长在甘特图上是否冲突
- **历史数据**：显示历史预约数据（如历史平均耗时）

#### [HN-03] 资源分配与发布
- **通知触发**：点击"确认发布"后，系统向Sales推送最终确定的时间段

### 4.3 医生协同端（Doctor）

#### [DOC-01] 预约握手
- **待办列表**：展示销售发起的"面诊/解读"申请
- **操作**：接受/拒绝/改期，拒绝/改期时必须填写"建议时间"

### 4.4 执行端（护士）

#### [NUR-01] 任务执行
- **我的任务**：仅展示分配给自己的工单
- **状态流转**：Check-in（客户到达）→ Start（开始服务）→ Finish（服务结束）
- **超时反馈**：若实际执行时间>预约时间20%，强制填写备注

## 5. 异常场景处理

### 5.1 预约撞单
- **处理方式**：数据库层采用乐观锁，后提交者提示"该时段刚刚已被占用，请刷新重试"

### 5.2 护士临时请假
- **处理**：护士长将该护士状态置为Unavailable，系统自动筛选受影响的未来预约

### 5.3 急单资源爆满
- **处理方式**：允许急单"重叠排班"，甘特图显示两张卡片层叠，护士长线下协调

## 8. 系统设计风格

### 8.1 配色方案
- 主色调：医疗蓝（#4A90E2）搭配清新绿（#7ED321）
- 警告色：橙红色（#FF6B35）用于紧急预约提示
- 状态色：甘特图采用彩色图例区分不同预约状态

### 8.2 视觉细节
- 圆角设计：卡片式布局，统一8px圆角
- 时间轴：采用渐变色填充表示时间段状态
- 图标风格：线性图标配合实色填充，简洁现代

### 8.3 整体布局
- 销售端：卡片式布局，突出预约流程步骤
- 护士长端：甘特图网格布局，支持拖拽操作
- 医生端：列表式布局，便于快速处理预约申请
