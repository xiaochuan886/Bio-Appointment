# 钉钉同步快速参考

## 🚀 快速开始

### 1. 配置钉钉同步（5分钟）

```
1. 登录系统（使用超级管理员账号）
2. 进入"用户管理" → "钉钉同步"标签
3. 点击"配置"按钮
4. 填写钉钉应用信息：
   - AppKey: 从钉钉开发者后台获取
   - AppSecret: 从钉钉开发者后台获取
   - AgentId: 从钉钉开发者后台获取
   - CorpId: 企业ID
5. 设置同步选项：
   - 启用同步：✅
   - 冲突策略：以钉钉数据为准
6. 点击"保存配置"
```

### 2. 执行首次同步（2分钟）

```
1. 在钉钉同步面板
2. 点击"立即同步"按钮
3. 等待同步完成
4. 查看同步结果统计
5. 切换到"用户列表"验证同步的用户
```

## 🔑 关键信息

### 权限要求

| 操作 | 所需权限 |
|------|---------|
| 配置钉钉同步 | super_admin |
| 触发同步 | super_admin |
| 查看同步日志 | super_admin |
| 查看用户列表 | 所有角色 |

### 钉钉应用权限

必需权限：
- ✅ 通讯录管理 → 成员信息读权限
- ✅ 通讯录管理 → 部门信息读权限

### 数据映射

| 钉钉字段 | 本地字段 | 说明 |
|---------|---------|------|
| userid | username | 用户名 |
| name | full_name | 真实姓名 |
| mobile | - | 用于生成密码 |
| dept_id_list | department | 部门信息 |

### 默认配置

```javascript
{
  sync_enabled: true,           // 启用同步
  auto_sync_enabled: false,     // 不启用自动同步
  sync_schedule: 'daily',       // 每天同步
  sync_time: '02:00:00',        // 凌晨2点
  conflict_strategy: 'dingtalk_first'  // 以钉钉为准
}
```

## 🐛 常见问题速查

### 问题：保存配置一直显示"保存中..."

**快速检查：**
```javascript
// 在浏览器 Console 中执行
const { data: { user } } = await supabase.auth.getUser();
const { data: profile } = await supabase
  .from('profiles')
  .select('role, status')
  .eq('id', user.id)
  .single();
console.log('角色:', profile.role, '状态:', profile.status);
// 应该显示：角色: super_admin 状态: active
```

**解决方案：**
1. 确认是超级管理员
2. 查看 Console 错误日志
3. 刷新页面重新登录

### 问题：同步失败

**快速检查：**
```javascript
// 检查配置
const { data } = await supabase
  .from('dingtalk_sync_config')
  .select('*')
  .single();
console.log('配置:', data);
```

**解决方案：**
1. 验证 AppKey 和 AppSecret
2. 检查网络连接
3. 确认钉钉应用已启用
4. 查看同步日志的错误详情

### 问题：部分用户同步失败

**快速检查：**
```javascript
// 查看最近的同步日志
const { data } = await supabase
  .from('dingtalk_sync_logs')
  .select('*')
  .order('created_at', { ascending: false })
  .limit(1)
  .single();
console.log('日志:', data);
```

**解决方案：**
1. 查看日志中的 error_message
2. 检查失败用户的数据
3. 手动修正后重新同步
