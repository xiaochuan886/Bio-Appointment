# 📅 日期筛选器优化文档

## 版本信息
- **版本号**: v1.3.0
- **更新日期**: 2025-11-27
- **更新内容**: 日期筛选器优化，支持日/周/月独立筛选

## 问题分析

### 核心问题
当前所有视图（日、周、月）共用了同一个"按日筛选"的逻辑，这导致：
1. ❌ 周视图只能显示选中日期当天的数据，无法展示整周数据
2. ❌ 月视图只能显示选中日期当天的数据，无法展示整月数据
3. ❌ 用户体验不佳，无法直观地查看周/月的完整排班情况

### 目标
为不同视图实现独立且匹配其时间跨度的筛选功能：
- **日视图**：筛选器精确到具体某一天（YYYY-MM-DD）
- **周视图**：筛选器选择某一周，展示该周（周一到周日）的全部数据
- **月视图**：筛选器选择某一月份，展示该月（1日到月末）的全部数据

## 优化方案

### 1. 新增DateRangePicker组件 ✨

创建了独立的日期范围选择器组件，根据视图模式动态切换：

#### 组件特性
- **智能切换**：根据当前视图模式自动切换选择器类型
- **快速导航**：提供上一个/下一个/今天按钮
- **时间范围提示**：清晰显示当前筛选的时间范围

#### 三种模式

##### 日视图模式
- **选择器类型**：日历选择器
- **显示格式**：
  - 完整：`2025年11月28日 星期四`
  - 简短：`11月28日`
- **操作**：点击日历选择具体日期

##### 周视图模式
- **选择器类型**：周选择器（带周数的日历）
- **显示格式**：
  - 完整：`第48周（11月24日 - 11月30日）`
  - 简短：`第48周`
- **操作**：点击日历中任意日期，自动选择该日期所在的周
- **周定义**：周一为一周的开始

##### 月视图模式
- **选择器类型**：年月选择器
- **显示格式**：
  - 完整：`2025年11月`
  - 简短：`2025年11月`
- **操作**：通过下拉框选择年份和月份

#### 快速导航功能
- **上一个按钮**：
  - 日视图：前一天
  - 周视图：上一周
  - 月视图：上一月
- **下一个按钮**：
  - 日视图：后一天
  - 周视图：下一周
  - 月视图：下一月
- **今天按钮**：快速回到当前日期

### 2. 数据查询优化 🔍

#### API更新
更新`getSchedules`函数，支持日期范围查询：

```typescript
export async function getSchedules(filters?: {
  date?: string;          // 单日查询
  startDate?: string;     // 范围查询开始日期
  endDate?: string;       // 范围查询结束日期
  status?: string;
  appointment_id?: string;
})
```

#### 查询逻辑
- **单日查询**：`date`参数，精确匹配
- **范围查询**：`startDate`和`endDate`参数，使用`gte`和`lte`
- **灵活查询**：支持只有开始日期或只有结束日期

#### 数据加载策略
根据视图模式自动计算日期范围：

```typescript
switch (viewMode) {
  case 'day':
    // 查询单日数据
    startDate = endDate = format(selectedDate, 'yyyy-MM-dd');
    break;
  case 'week':
    // 查询整周数据（周一到周日）
    const weekStart = startOfWeek(selectedDate, { weekStartsOn: 1 });
    const weekEnd = endOfWeek(selectedDate, { weekStartsOn: 1 });
    startDate = format(weekStart, 'yyyy-MM-dd');
    endDate = format(weekEnd, 'yyyy-MM-dd');
    break;
  case 'month':
    // 查询整月数据（1日到月末）
    const monthStart = startOfMonth(selectedDate);
    const monthEnd = endOfMonth(selectedDate);
    startDate = format(monthStart, 'yyyy-MM-dd');
    endDate = format(monthEnd, 'yyyy-MM-dd');
    break;
}
```

### 3. 界面交互优化 🎨

#### 响应式设计
- **桌面端**：显示完整的时间范围提示文字
- **移动端**：隐藏完整提示，只显示简短格式

#### 视觉反馈
- **按钮状态**：悬停和点击都有明确的视觉反馈
- **图标提示**：使用ChevronLeft、ChevronRight、CalendarIcon图标
- **对齐方式**：选择器弹出框右对齐，避免遮挡

#### 用户体验
- **一键切换**：点击视图切换按钮，日期筛选器自动适配
- **保持日期**：切换视图时，保持当前选中的日期
- **智能提示**：周视图和月视图显示"点击任意日期选择该周/月"

### 4. 数据联动规则 🔄

#### 视图切换联动
1. 用户切换视图模式
2. DateRangePicker自动更新显示格式
3. 触发数据重新加载
4. 根据新视图模式计算日期范围
5. 查询并展示对应时间段的数据

#### 日期变更联动
1. 用户选择新日期
2. 触发数据重新加载
3. 根据当前视图模式计算日期范围
4. 查询并展示对应时间段的数据

#### 依赖关系
