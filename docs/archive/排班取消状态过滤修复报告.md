# 排班取消状态过滤修复报告

## 问题描述

在排班页面的周视图和月视图中，显示了已取消的排班，这会让护士误解排班情况。例如，周二应该只显示22个有效排班，但实际显示了23个（包含1个已取消的排班）。

## 修复方案

### 1. 甘特图组件修复 (`src/components/appointment/GanttChart.tsx`)

**修改内容：**
- 在周视图和月视图中，过滤掉状态为 `cancelled` 的排班
- 添加调试日志来跟踪过滤过程

**具体修改：**
```typescript
// 在周视图和月视图中，过滤掉已取消的排班
if (viewMode === 'week' || viewMode === 'month') {
  const originalCount = schedules.length;
  visibleSchedules = schedules.filter(schedule => schedule.status !== 'cancelled');
  const filteredCount = visibleSchedules.length;
  const cancelledCount = originalCount - filteredCount;
  
  // 调试日志
  console.log(`[GanttChart] ${viewMode}视图过滤排班:`, {
    原始排班数: originalCount,
    过滤后排班数: filteredCount,
    已取消排班数: cancelledCount,
    已取消排班: schedules.filter(s => s.status === 'cancelled').map(s => ({
      id: s.id,
      status: s.status,
      customer: s.appointment?.customer_name,
      date: s.scheduled_date
    }))
  });
}
```

### 2. 护士排班页面修复 (`src/pages/nurse/SchedulePage.tsx`)

**修改内容：**
- 修改 `getSchedulesForDate` 函数，过滤掉已取消的排班
- 修改统计卡片中的总排班数，排除已取消的排班

**具体修改：**
```typescript
const getSchedulesForDate = (date: Date) => {
  const dateStr = format(date, 'yyyy-MM-dd');
  return schedules.filter(schedule => {
    const scheduleDate = format(parseISO(schedule.scheduled_date), 'yyyy-MM-dd');
    // 过滤掉已取消的排班，避免护士误解排班情况
    return scheduleDate === dateStr && schedule.status !== 'cancelled';
  });
};

// 统计卡片修改
<div className="text-2xl font-bold">{schedules.filter(s => s.status !== 'cancelled').length}</div>
```

### 3. 护士长排班页面修复 (`src/pages/head-nurse/SchedulePage.tsx`)

**修改内容：**
- 修改今日排班统计，排除已取消的排班

**具体修改：**
```typescript
// 排除已取消的排班，避免误导护士长
const todaySchedules = schedules.filter(s => s.status !== 'cancelled').length;
```
