# 创建测试用户指南

## 🎯 问题分析

登录一直显示"登录中"可能是因为：
1. 数据库中没有测试用户
2. 用户的 profile 记录缺失
3. 登录 API 调用超时或失败

## 📝 创建测试用户的方法

### 方法 1：通过注册页面创建（推荐）

1. **访问注册页面**
   - 在登录页面点击"立即注册"链接
   - 或直接访问 `/register` 路由

2. **填写注册信息**
   - 用户名：`admin`（或任意用户名，3-20字符）
   - 密码：`123456`（至少6字符）
   - 真实姓名：`管理员`（可选）

3. **提交注册**
   - 点击"注册"按钮
   - 第一个注册的用户会自动成为超级管理员

4. **登录测试**
   - 注册成功后会自动跳转到登录页
   - 使用刚才注册的用户名和密码登录

### 方法 2：通过 SQL 直接创建

如果注册功能也有问题，可以直接在数据库中创建用户：

```sql
-- 注意：这个方法需要访问 Supabase 数据库管理界面

-- 1. 首先在 auth.users 表中创建用户
-- 这需要通过 Supabase Auth API 或管理界面完成

-- 2. 然后在 profiles 表中创建对应的 profile
INSERT INTO profiles (id, username, email, full_name, role, status)
VALUES (
  'user-uuid-here',  -- 替换为实际的用户 UUID
  'admin',
  'admin@miaoda.com',
  '管理员',
  'super_admin'::user_role,
  'active'::user_status
);
```

## 🔍 调试步骤

### 1. 打开浏览器开发者工具

按 F12 打开开发者工具，切换到 Console 标签。

### 2. 尝试注册

1. 访问注册页面
2. 填写注册信息
3. 观察控制台输出

**预期输出：**
```
开始注册流程，用户名: admin
注册成功
```

**如果出错：**
查看错误信息，可能是：
- 用户名已存在
- 密码不符合要求
- 数据库连接失败

### 3. 尝试登录

1. 使用注册的用户名和密码
2. 点击登录
3. 观察控制台输出

**预期输出：**
```
=== 开始登录流程 ===
表单值: { username: 'admin', password: '***' }
1. 调用 login API...
开始登录流程，用户名: admin
尝试使用邮箱登录: admin@miaoda.com
登录成功，用户 ID: xxx-xxx-xxx
获取 profile 成功: { ... }
2. 登录 API 返回结果: { hasUser: true, hasSession: true, hasProfile: true }
3. 刷新用户信息...
4. 显示成功提示...
5. 跳转到首页...
=== 登录流程完成 ===
```

**如果卡在某一步：**
- 卡在步骤 1：检查网络连接
- 卡在步骤 2：检查用户名和密码是否正确
- 卡在步骤 3：检查 AuthContext 是否正常
- 卡在步骤 5：检查路由配置

## 🐛 常见问题

### 问题 1：注册时提示"用户名已存在"

**解决方法：**
- 使用不同的用户名
- 或者删除现有用户后重新注册

### 问题 2：登录时提示"Invalid login credentials"

**可能原因：**
- 用户名或密码错误
- 用户不存在
- 用户状态为 disabled

**解决方法：**
1. 确认用户名和密码正确
2. 尝试重新注册
3. 检查数据库中的用户记录

### 问题 3：登录成功但没有跳转

**可能原因：**
- 路由配置问题
- 权限验证失败
- Profile 数据缺失

**解决方法：**
1. 检查控制台错误信息
2. 查看 Network 标签中的请求
3. 确认用户有 profile 记录

### 问题 4：一直显示"登录中..."

**可能原因：**
- API 调用超时
- 网络连接问题
- 数据库查询失败

**解决方法：**
1. 查看控制台的详细日志
2. 检查 Network 标签中的请求状态
3. 确认 Supabase 配置正确

## 📊 验证用户创建成功

### 通过控制台验证

在浏览器控制台输入：

```javascript
// 查看当前用户
const { data: { user } } = await supabase.auth.getUser();
console.log('当前用户:', user);

// 查看 profile
const { data: profile } = await supabase
  .from('profiles')
  .select('*')
  .eq('id', user.id)
  .single();
console.log('用户 Profile:', profile);
```

### 通过 Supabase 管理界面验证

1. 访问 Supabase 项目管理界面
2. 进入 Authentication > Users
3. 查看用户列表
4. 进入 Table Editor > profiles
5. 查看 profile 记录
