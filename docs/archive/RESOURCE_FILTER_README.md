## 🎯 功能概述

资源筛选功能允许护士长在资源看板上按资源类型筛选显示内容：

- ✅ **护士筛选**：仅显示护士和护士长资源
- ✅ **房间筛选**：仅显示房间资源
- ✅ **多选支持**：可单选、多选或不选
- ✅ **实时更新**：选择后立即刷新
- ✅ **状态指示**：清晰的筛选状态标识
