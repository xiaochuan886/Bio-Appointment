# Bio-Appointment系统Bug修复说明

## ✅ 最新修复（2025-11-27）

### Bug #5: 修正时长输入报错

**问题**：护士长在排班时修改"修正时长"字段后提交，系统报错："Expected string, received number"

**原因**：表单验证schema期望字符串类型，但Input组件返回数字类型

**修复**：
1. ✅ 修改Schema定义：`z.string().optional()` → `z.number().optional()`
2. ✅ 修改表单初始化：直接使用数字类型
3. ✅ 改进Input组件：正确处理空值
4. ✅ 移除多余的类型转换

**验证结果**：
- ✅ 可以正常输入修正时长
- ✅ 不再显示类型错误
- ✅ 排班数据正确保存
- ✅ 代码通过lint检查
